# Monte Carlo Simulations

While trying to learn about Monte Carlo Simulations, I tried to code it out using two applications:

1. I tried to get the probability of two scenarios with a shuffled deck of cards: probability that two kings might appear together, and the probability that a king and a queen will appear together.
2. I tried to predict and analyse the stock price of a ticker using MCS.

The first experiment plays into estimating probability using Law of Large Numbers, whereas the second experiment was just a fun finance thing I tried to do.

# Results
The proababilties are being computed properly only, as the law of large numbers takes effect. However, the predictions are not at all accurate, which is understandable as this is a very basic implementation of the Monte Carlo simulation for prediction financial stock trends.
